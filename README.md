## Covid Case Count
The map shows the Covid-19 case rate in conjunction to the population size.
**Question:** The map answers the Coid-19 case rate compared to the population size in New York.
**Data:** NYC Department of Health and Mental Hygiene, U.S. Census Bureau, 2020.
**Method:** I utilized the map feature on ArcGIS to create the image. I started with located the area where I was plotting the Covid-19 outbreak. I used the contents plane and catalog plane to add specific pieces of information to the map.
**A design choice I made and why:** I chose a color pallet that was easily visible. It makes it clear to see the difference between the Covid case count and the population area.
**A limitation of this map:** The limitation of this map is that it is hard to read the city names underneath the yellow circles.

## Covid-19 Case Rate
The map shows the Covid-19 case rates within New York.
**Question:** The map shows the Covid-19 case rate within different cities located within the state of New York.
**Data:** NYC Department of Health and Mental Hygiene, U.S. Census Bureau, 2020.
**Method:** I utilized the map feature on ArcGIS to create the image. I located the state of New York and added an attribute table which provided me with the numbers for the rates. I used the symbology pane to change the color of the images which allows the map to be easily read.  
**A design choice I made and why:** I used colors that were easy to understand with a legend box. The yellow shows the smaller amount of Covid-19 rates, while as the color gets more dark, the numbers increase. 
**A limitation of this map:** The limitation of this map is it only has the popular areas of New York labeled for the reader to view.
